Descrição detalhada

Converte cliques do mouse em coordenadas de tabuleiro (linha, coluna).

O GameController não processa regras de jogo nem desenha nada — ele só traduz posições de tela (pixels) para posições de matriz, usando os mesmos parâmetros de tamanho/deslocamento que o BoardRenderer usa para desenhar, garantindo que clique e desenho fiquem sincronizados.

◆ awardRandomWeapon()

WeaponType GameController::awardRandomWeapon ( )

Concede ao jogador uma arma especial escolhida aleatoriamente entre míssil e torpedo, incrementando o estoque correspondente.

Chamado pela tela de jogo sempre que o jogador afunda um navio inimigo — é assim que o jogador "ganha" acesso às armas especiais, que começam zeradas.

Retorna
O WeaponType sorteado (MISSILE ou TORPEDO), para a tela de jogo poder montar a mensagem "Voce ganhou 1 missil/torpedo!".

Processa um disparo da arma atualmente selecionada contra o tabuleiro e a frota inimiga, cobrindo de uma vez todas as células afetadas (diferente de fireBasic/fireMissile/fireTorpedo, que só atualizam o Board — aqui o dano também é propagado para os Ship da frota, para a tela de jogo saber quando um navio afunda).

Consome a munição da arma usada (se especial) e volta a seleção para BASIC, assim como fireMissile()/fireTorpedo().

Parâmetros
enemyTabuleiro do adversário.
enemyShipsFrota do adversário, para propagar dano e detectar afundamentos.
rowLinha clicada (âncora do disparo).
colColuna clicada (âncora do disparo).
Retorna
FireResult com acertos, erros e navios afundados neste disparo.
