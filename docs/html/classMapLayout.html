Descrição detalhada

Aplica o layout de terreno de cada mapa nos tabuleiros.

MapLayout é uma classe utilitária (sem estado) que define onde ficam células BLOCKED e SHALLOW em cada tipo de mapa. Deve ser chamado uma única vez pelo GameState após criar os boards, antes de qualquer posicionamento de navios.

Por que uma classe separada e não métodos no Board? O Board não sabe nada sobre mapas, ele só armazena células. A decisão de qual terreno fica em qual posição é responsabilidade do domínio do jogo, não da estrutura de dados.

Aplica o terreno correto no board conforme o mapa escolhido.

Chama setCell() no board para marcar células como BLOCKED ou SHALLOW conforme o design de cada mapa. Deve ser aplicado nos dois boards (jogador e computador) para que as regras de terreno sejam simétricas.

Parâmetros
boardReferência ao tabuleiro onde o terreno será aplicado.
mapTipo do mapa selecionado pelo jogador.
Aviso
Chamar apply() após navios já posicionados pode corromper o estado do tabuleiro. Sempre aplique antes da fase de posicionamento.
