Descrição detalhada

Gerencia o tabuleiro do jogo de Batalha Naval.

A classe Board é responsável por manter o estado de todas as células do tabuleiro, validar posicionamento de navios, processar tiros e verificar condições de fim de jogo.

Arquitetura: O Board é a única entidade que manipula diretamente a matriz de células, garantindo encapsulamento e integridade dos dados. O GameController não pode acessar a grid diretamente.

Suporte a terrenos especiais (BLOCKED e SHALLOW)

void Board::clearShips ( )

Remove todos os navios do tabuleiro, sem afetar o terreno.

Volta toda célula CellState::SHIP para CellState::EMPTY. Terrenos (BLOCKED/SHALLOW) e tiros já registrados (HIT/MISS) são preservados,ao contrário de reset(), que apaga tudo.

Remove um navio previamente posicionado no tabuleiro.

Restaura as células ocupadas pelo navio para o estado CellState::EMPTY. Utilizado principalmente para desfazer operações de posicionamento durante a fase de setup ou para algoritmos de backtracking.

Parâmetros
rowLinha inicial onde a proa do navio está posicionada.
colColuna inicial onde a proa do navio está posicionada.
sizeTamanho do navio em número de células.
horizontaltrue se o navio está na orientação horizontal, false se vertical.
Aviso
Certifique-se de que o navio realmente existe nesta posição, pois o método não verifica se as células contêm CellState::SHIP. Remover um navio inexistente pode corromper o estado de células adjacentes.

◆ shoot()

CellState Board::shoot ( int  row,
int  col 
)

Processa um tiro na coordenada especificada.

Atualiza o estado da célula atingida:

  • CellState::SHIP passa para CellState::HIT (acerto)
  • CellState::EMPTY, BLOCKED ou SHALLOW passam para CellState::MISS (erro)
Parâmetros
rowLinha da coordenada do tiro.
colColuna da coordenada do tiro.
Retorna
O NOVO estado da célula após o tiro (HIT ou MISS). Se o tiro for inválido, retorna o estado atual sem modificar.
Aviso
Este método não valida se o tiro é válido. Use isValidShot() antes de chamar shoot() para garantir que o tiro não seja repetido.
Veja também
isValidShot() para verificar se o tiro é permitido.
