Descrição detalhada

Representa uma entrada individual do ranking de pontuação.

Agrupa os dados de uma partida finalizada: nome do jogador, pontuação obtida, tempo decorrido (usado como critério de desempate) e o tipo de mapa jogado (para segmentar rankings por mapa).
