Descrição detalhada

Gerencia a persistência do ranking de pontuações via SQLite.

A classe Database encapsula toda a comunicação com o banco SQLite, escondendo os detalhes da API C do sqlite3 (por isso o ponteiro do banco é armazenado como void*, evitando expor <sqlite3.h> no header). Cria automaticamente a tabela de ranking, caso não exista, ao ser construída.
