Descrição detalhada

Tela de menu principal e de seleção de mapa.

Desenha o visual "carta náutica" compartilhado com as demais telas (via UiTheme) e expõe dois fluxos bloqueantes: showMainMenu(), com os botões do menu (Iniciar Jogo/Ranking/Como Jogar/Sair), e showMapSelection(), com os cartões dos três mapas disponíveis.

◆ showMainMenu()

MenuOption MenuScreen::showMainMenu ( )

Mostra o menu principal e bloqueia até o jogador escolher uma opção.

Desenha o título e os botões (Iniciar Jogo/Ranking/Como Jogar/Sair) em loop, com efeito de destaque no botão sob o cursor, até que algum deles seja clicado ou a janela seja fechada.

Retorna
A MenuOption escolhida, ou MenuOption::EXIT se a janela for fechada.

◆ showMapSelection()

MapType MenuScreen::showMapSelection ( )

Mostra a tela de seleção de mapa e bloqueia até o jogador escolher um.

Desenha os três cartões de mapa (Açude 5x5, Lago 8x8 e Oceano 10x10), cada um com uma miniatura do tabuleiro, em loop, até que algum seja clicado ou a janela seja fechada.

Retorna
O MapType escolhido, ou MapType::OCEANO se a janela for fechada.
